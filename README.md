# GY-302 (BH1750FVI) low-cost light sensor: calibration dataset and analysis code

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24308933.svg)](https://doi.org/10.5281/zenodo.24308933)
[![Data: CC BY 4.0](https://img.shields.io/badge/data-CC%20BY%204.0-lightgrey.svg)](data/LICENSE-DATA.md)
[![Code: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)

This repository contains the complete paired dataset and the analysis code supporting the article:

> Carvalho Neto, J. A.; Fontana, R. Y. A.; Gimenes, A. L. V.; Frigo, M. M.; Caneppele, F. L.
> *Laboratory Calibration and Agreement Assessment of a Low-Cost Digital Light Sensor (GY-302/BH1750FVI) for Broiler House Illuminance Monitoring.* Journal of Sensors (under review).

The measurements were originally collected during the master's research of J. A. Carvalho Neto (*Sistema de iluminação de granjas controladas por lógica fuzzy*, Faculdade de Ciências Agronômicas, Unesp, Botucatu, 2021; Tables 5 and 6). The values are transcribed verbatim. No observation was added, removed or modified.

## Experimental context (summary)

| Item | Description |
|---|---|
| Sensor under test | GY-302 module (Rohm BH1750FVI), I²C, `CONTINUOUS_HIGH_RES_MODE`, integer (1 lx) output, Arduino Mega |
| Reference instrument | ITR-3000 digital luxmeter (silicon photodiode; 20 lx range resolution 0.01 lx). Manufacturer accuracy: ±3 % of reading for incandescent light (2854 K), **±6 % of reading for other visible sources (LED)**; cosine deviation ±2 % at 30°, ±6 % at 60° |
| Light source | LED lamp in a luminaire, 1.70 m from the sensor, dimmed by an Arduino Dimmer Shield (Triac phase control, 2 % steps) |
| Conditions | Laboratory bench, night-time, no daylight; single sensor unit |
| Stage 1 (calibration) | 26 pairs, raw GY-302 vs. reference, 1.2 to 41.5 lx |
| Stage 2 (validation) | 22 independent pairs, firmware-corrected GY-302 vs. reference, 1.78 to 43.3 lx |

### Correction actually implemented in firmware

```c
uint16_t lux = lightMeter.readLightLevel();
int lux2 = 0.7777*lux - 0.4562;   // Eq. (9): float -> int conversion TRUNCATES toward zero
```

The corrected values in Stage 2 are therefore `trunc(0.7777·raw − 0.4562)`. Truncation introduces an expected systematic error of about −0.5 lx (see `results/`). See `firmware/gy302_correction_excerpt.ino`.

## Data dictionary

**`data/calibration_stage1_table5.csv`**

| Column | Unit | Description |
|---|---|---|
| `obs` | – | Observation index (order as in the original table, decreasing illuminance) |
| `gy302_raw_lx` | lx | Raw GY-302 reading (no moving average) |
| `gy302_raw_movavg_lx` | lx | Raw GY-302 reading with moving-average filter (identical to the column above in every row) |
| `ref_itr3000_lx` | lx | ITR-3000 reference reading |

**`data/validation_stage2_table6.csv`**

| Column | Unit | Description |
|---|---|---|
| `obs` | – | Observation index |
| `gy302_corrected_lx` | lx | Firmware-corrected GY-302 output (Eq. 9, truncated to integer) |
| `gy302_corrected_movavg_lx` | lx | Same with moving-average filter (identical) |
| `ref_itr3000_lx` | lx | ITR-3000 reference reading |

Decimal separator: point. Field separator: comma. Encoding: UTF-8.

## Metrics computed

All accuracy metrics are **direct errors** `e = sensor − reference`. No second regression is fitted before computing them.

- Bias (mean error) with 95 % CI and t-test, SD of differences, MAE, RMSE, maximum absolute error, MAPE
- Bland–Altman 95 % limits of agreement (with approximate CIs) and a proportional-bias test
- Leave-one-out cross-validation on Stage 1, so that raw and corrected outputs are compared on the **same** pairs
- Number of points within the reference instrument tolerance (±6 %, LED)
- GUM-style uncertainty budget (k = 2) for the corrected sensor at 2 to 40 lx
- Regression fits (Stage 1, i.e. Eq. 9, and the former Stage 2 refit), kept for traceability only. **These are not accuracy metrics.**

Rounding versus truncation: `stage1_LOOCV_round` simulates round-to-nearest exactly on the Stage-1 pairs (raw readings available). `stage2_sensitivity_round_equiv` adds a constant +0.5 lx, the expected effect of rounding, to the Stage-2 outputs; it is a **sensitivity analysis**, not measured data. `stage2_lag1_autocorr_differences` reports serial dependence, which is why the confidence intervals should be regarded as approximate.

The uncertainty budget is **conditional**: the ITR-3000 has no calibration certificate, so the budget assumes the instrument meets its nominal ±6% specification.

## Reproducing the results

Requires Python ≥ 3.10.

```bash
pip install -r requirements.txt
python code/reanalysis_direct_errors.py
python code/make_manuscript_figures.py
```

The output is written to `results/`. The script reproduces Eq. (9) of the dissertation (slope 0.7777, intercept −0.4562, R² = 0.9985).

## Limitations

The data come from a single GY-302 unit, a single LED source, laboratory conditions and the 1 to 45 lx range. The ITR-3000 accuracy for LED light (±6 %) bounds the attainable accuracy statement. The results should not be generalised to other BH1750 units, other light spectra, or broiler-house environmental conditions (dust, humidity, temperature, drift) without further validation.
